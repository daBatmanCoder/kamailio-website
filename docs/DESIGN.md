# Design direction: The signal network

Kamailio is foundational communications infrastructure with 25 years of open development. The redesign makes that technical strength visible while keeping the documentation and community within easy reach.

## Visual system

Near-black (#090c0a), warm white (#eff0e9), electric green (#b6f581), and pale mineral green (#e9ede2). Manrope provides the large editorial typography; IBM Plex Mono identifies technical metadata. Fine rules, a subtle grid, orbital paths, and restrained motion carry the network metaphor. A custom geometric K mark accompanies the Kamailio name; it is a proposed identity treatment for this concept, not an official replacement logo.

The homepage moves through the platform promise, project facts, capabilities, an interactive architecture example, developer workflow, ecosystem, current news, community, and a final build action. The light architecture section creates a visual change in pace and makes the signaling role tangible. There are no fabricated testimonials, customer counts, or live performance indicators.

## References reviewed

- https://www.kamailio.org/w/ — authoritative current content and structure
- https://www.awwwards.com/sites/hyperbolic — technical identity, oversized typography, and abstract network imagery
- https://www.awwwards.com/inspiration/thumbnail-submission-647a542e33ab7858124955 — desktop composition reference
- https://mobbin.com/ — strong hierarchy, clear actions, progressive disclosure, and publicly visible product screens

Mobbin’s public site and displayed screen examples were reviewed. No access to its subscriber-only library is implied. Design references informed the approach; artwork and components were created for this implementation.

## Content architecture

1. Platform: capabilities and the complete feature reference
2. Documentation: local module manuals, versioned wiki/cookbooks, tutorials, APIs, database schemas, legacy references, conference materials, and source coverage
3. Community: mailing lists, Matrix, events, commercial support, donation and contact
4. About: history, governance, and users
5. Resources: full directory and every imported page
6. News: searchable/filterable full archive
7. Download: current release, source, package instructions, and upgrades

The source archive preserves technical details and historic announcements. New presentation pages summarize and reorganize them. The documentation hub extends the dark signal-network identity with orbital code imagery, large editorial typography, and a searchable modular library. Technical readers use a light surface, readable typography, a persistent topic sidebar, and a searchable outline. Dark code panels preserve formatting and offer copy actions. Mobile navigation and outlines open on demand. Original source and release attribution remain visible throughout.
